## 3. 同一カード内の効果関係

### 3.1 叫喚と憎悪

- モード2とモード3を別の効果として設定・集計する。
- 1回のプレイで4モード中2つを選べるため、モード2とモード3は同時選択できる。
- モード2使用回数を`u2`、モード3使用回数を`u3`とした場合、両方を最適に組み合わせるために必要なカード使用回数の最小値は`max(u2, u3)`となる。
- 画面では各モードの使用上限と、必要なカード使用回数を分けて表示する。

### 3.2 尽小花・イマリ

- ファンファーレと超進化を別の効果として設定・集計する。
- 同じカード実体で両方が働く場合があるため、使用回数を単純加算してカード枚数と比較しない。
- 画面ではファンファーレ使用回数と超進化使用回数を個別入力する。

## 4. 通常ドローの扱い

- ターン開始時の通常ドローと、簡易版で指定する「次のN枚」は確率計算の基礎として残す。
- カード効果が「条件なしで山札からN枚引く」だけの通常ドローカードは、対応カード一覧へ登録しない。
- 本一覧にないカード効果は、山札からカードを引く効果を持っていても自動適用しない。
